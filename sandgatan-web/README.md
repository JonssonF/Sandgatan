# sandgatan-web

Frontend for [Sandgatan](../README.md) — React + TypeScript + Vite + Mantine + TanStack Query, built
as an installable PWA.

See the [repo root README](../README.md) for setup, environment variables, and deployment.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build
npm run lint
```
